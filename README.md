# 🌐 Personal Developer Portfolio — `proestofpros.github.io`

A lightweight, fast-loading personal developer portfolio website built with semantic **HTML5**, **CSS3**, and vanilla **JavaScript**. Styled with a terminal-inspired dark aesthetic (`Fira Code` monospace typography, neon green/cyan accents, and an interactive typewriter header).

---

## 📂 Repository Structure

```text
proestofpros.github.io/
├── index.html   # Main portfolio structure, bio, projects, and contact links
├── style.css    # Dark terminal theme using Fira Code font and responsive layout
├── script.js    # Typewriter effect animation for the hero tagline
├── LICENSE      # MIT License
└── README.md    # Project documentation
```

---

## ✨ Features

- **Terminal-Inspired UI**: High-contrast dark theme (`#0a0a0a`) with `#00ff7f` and `#00bfff` syntax-highlighted accents.
- **Typewriter Hero Animation**: Dynamic character-by-character tagline rendering on page load (`script.js`).
- **Zero Dependencies**: Pure HTML/CSS/JS — deploys directly on GitHub Pages with instant load times.

---

## 🚀 Local Preview

1. Clone the repository:
   ```bash
   git clone https://github.com/sparsh0106/proestofpros.github.io.git
   cd proestofpros.github.io
   ```
2. Open `index.html` in any web browser, or serve locally:
   ```bash
   python3 -m http.server 8000
   ```
